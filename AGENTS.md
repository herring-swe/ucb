# AGENTS.md

Project notes and rules for any LLM/agent working in this repository.

## Scope of work

- This is a cross-platform foundation C library. Own functions (prefixed with `ucb_`) *should* be used instead of standard library functions when possible and where it makes sense.
- ucb_malloc/calloc/realloc must be paired with ucb_free. These functions track memory allocations and report leaks.
- Investigate or debug issues **only when explicitly asked**. Do not go off fixing,
  refactoring, or investigating unrelated problems encountered along the way.
  If you notice something suspicious that was not part of the request, note it in
  your summary but do not act on it.
- Make minimal, targeted changes. Match existing code conventions.
- All files can be checked for formatting errors with tools/fix.py
  - `--type` can take value `c` or `python` for specific language checks
  - `--fix` will attempt to fix formatting errors
  - We call our own clang-format binary to avoid version mismatches
- Files that are autogenerated, do not edit the output files directly. See CMake definitions.
  - Header templates:
    - Inputs: `include/ucb/container/templates/vector_template.h`
    - Outputs: `include/ucb/container/impl/*`, `src/ucb/container/container/impl/*`
  - Unicode data is downloaded by CMake and processed by `tools/ucparser.py` into the build as headers and source files.

## Building

- CMake is the build system. Conan *could* be used for dependency management (in that case presets are generated), otherwise the build is used with cmake kits via vscode and the build folder is `build`.

## Debugging

Tests are checked against memory leaks (using ucb memory functions). To get the backtraces for leaks, use CMake option `UCB_MEMTRACK_BACKTRACE=ON` temporarily. This option is by default OFF since it has a significant performance impact.
