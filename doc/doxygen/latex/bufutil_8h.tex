Cast buffer into a type.
\begin{DoxyItemize}
\item If properly aligned to type, the same buffer will return as cast.
\item If not properly aligned, a new buffer will be allocated and the data copied.
\end{DoxyItemize}

Note that\+:
\begin{DoxyItemize}
\item If alignment is zero, the function will abort.
\item If buf is UCB\+\_\+\+NULL, the function will return UCB\+\_\+\+NULL.
\item If no elements fit in the buffer, the function will return UCB\+\_\+\+NULL.
\item If a new buffer is allocated, the user must free it with ucb\+\_\+free. Compare the pointer to the original.
\item The new buffer may be truncated to only contain complete elements. 
\end{DoxyItemize}
