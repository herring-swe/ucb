\doxysection{Unsafe}
\hypertarget{Unsafe-example}{}\label{Unsafe-example}A byte buffer for storing sequential data. It can have multiple implementations.

Allocate on heap with ucb\+\_\+buffer\+\_\+new\+\_\+$<$type$>$ or initiate on stack with ucb\+\_\+buffer\+\_\+init\+\_\+$<$type$>$

Only resize or free the buffer using the functions provided in the \doxylink{structucb__buffer}{ucb\+\_\+buffer} namespace.

The buffer is not thread safe.

\begin{DoxyWarning}{Warning}
All of the possible resize functions may invalidate pointers to the current memory. For this reason, it is recommended to only use offsets.
\end{DoxyWarning}
