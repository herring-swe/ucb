UCB_API bool ucb_str_abandon ( ucb_str * str,
char ** data,
size_t * len,
size_t * alloc )

Abandon managed data and return the underlying string.

The string data is no longer managed by str and must be managed by the caller.

str will be zeroed (same as calling ucb_str_release()). If str is heap allocated it must be followed by ucb_str_free(). It can be Reinitialized with any ucb_str_init function.

Note
This call will abandon the string, owned or not. Take a note of the return value.
Parameters
strthe string
dataoutput pointer to string data
lenoptional output pointer to C string length
allocoptional output pointer to C string allocated size
Returns
true if the string was owned (caller must free)
false if the string was wrapped

◆ ucb_str_adopt()

UCB_API void ucb_str_adopt ( ucb_str * str,
char * data,
size_t len,
size_t alloc )

Adopt memory as a string.

Release current data and take ownership of data, which will be freed when ucb_str_free() or ucb_str_release() is called.

The data must be allocated with ucb functions. The caller must not manipulate data after this call.

If len is zero, the string must be null-terminated and will be measured. If len is non-zero, the string may contain multiple null characters.

If alloc is zero, the allocation size is assumed to be len bytes.

◆ ucb_str_init()

UCB_API bool ucb_str_init ( ucb_str * str,
const char * cstr,
size_t len )

Initialize an owned string from a C string.

If cstr is UCB_NULL, it is treated as the empty string and len will be ignored.

If len is zero, the string must be null-terminated and will be measured. If len is non-zero, the string may contain multiple null characters.

str must always be released with ucb_str_release().

Warning
It doesn't perform any verifications on str data, which may lead to leaks if the string is already initialized.
Parameters
strstring to initialize
cstra C string or literal or UCB_NULL
len0 or length of string excluding null-terminator
Returns
true on success, false on allocation error

◆ ucb_str_reserve()

UCB_API bool ucb_str_reserve ( ucb_str * str,
size_t size )

Ensure at least size bytes of free space in string.

The current size is always the string length, regardless of null-terminator. It will add an extra byte when reallocating to ensure null-termination.

Wrapped strings will be detached and the current string copied over.

This is a no-op if the string is already large enough.

Parameters

sizebytes of free space to ensure.
Returns
true if the string has enough space.
false if out of memory
