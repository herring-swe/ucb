UCB_API bool ucb_str_detach ( ucb_str * str)

Creates own copy of the underlying string, null-terminated.

If str is an owned string, this call is a no-op If str is a wrapped string, a new allocation will be made, and the string will be owned and null-terminated.

Parameters
strstring to detach
Returns
true if the string was modified
false if the string is already owned or on out of memory
