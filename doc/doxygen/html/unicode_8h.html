◆ ucb_uc_next_char()

UCB_API size_t ucb_uc_next_char ( const char * str,
size_t len,
size_t from_byte )

Get the next character position.

Calls with from_byte >= string length (including UCB_NPOS) will return UCB_NPOS.

This function is only valid if called with from_byte being one of:

  • 0 (start of string)
  • a value returned from previous call
  • value from ucb_uc_char_index()

The string must not be modified between calls.

Parameters
strvalid UTF-8 string
lenlength of string (must be specified)
from_bytebyte offset to start from
Returns
byte offset to next character or UCB_NPOS if at end of string

Normalize an UTF-8 string.

The string must already have been validated as UTF-8.

If len is specified, the string may contain multiple null characters. If len is UCB_NPOS, the string must only be null-terminated.

Parameters
strstring to normalize, must be a valid utf-8 string
lenlength of string or UCB_NPOS
formthe normalization form to use
perroptional pointer that will be set on normalization error
Returns
result, with the normalized string on success
