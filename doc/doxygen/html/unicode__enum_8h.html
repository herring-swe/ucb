enum ucb_norm_form
Enumerator
UCB_NORM_INVALID 
UCB_NORM_NFD 

NFD - Canonical Decomposition Useful for case folding or searching (e.g., é → e + ´).

UCB_NORM_NFC 

NFC - Canonical Composition Same as NFD followed by canonical composition Useful for reducing the size of the string (e.g., e + ´ → é).

UCB_NORM_NFKD 

NFKD - Compatibility Decomposition As NFD, but also decomposes compatibility characters. Useful for compatibility equivalence (e.g., ½ → 1/2). NOTE: This is destructive, the produced string cannot be converted back to the original.

UCB_NORM_NFKC 

NFKC - Compatibility Composition. As NFC followed by a canonical composition (destructive). NOTE: This is destructive, the produced string cannot be converted back to the original.
