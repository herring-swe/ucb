UCB_API void * ucb_calloc ( size_t num,
size_t size )

Safe calloc. Allocate zeroied memory block. As stdlib calloc but:

  • If num or size is 0, will set UCB_ERROR_INVALID_ARG and return UCB_NULL.
  • If memory failed to allocate, will report fatal error UCB_ERROR_OUT_OF_MEMORY.
    Parameters
    numnumber of elements to allocate
    sizesize of each element
    Returns
    pointer to new memory or UCB_NULL

◆ ucb_realloc()

UCB_API void * ucb_realloc ( void * ptr,
size_t size )

Safe realloc. Reallocate memory block. As stdlib realloc but:

  • If ptr is NULL, will behave like ucb_malloc(size).
  • If size is 0, will behave like ucb_free(ptr) but set UCB_ERROR_INVALID_ARG.
  • If memory failed to allocate, will free ptr and call report fatal error UCB_ERROR_OUT_OF_MEMORY.
    Parameters
    ptrmemory to reallocate
    sizesize of new memory
    Returns
    pointer to new memory or UCB_NULL
