◆ UCB_MEMTRACK_ENABLE

#define UCB_MEMTRACK_ENABLE ( )
Value:
ucb_mem_tracking_enable()

Enable memory tracking.

Will start tracking all allocations made with ucb_malloc, ucb_calloc, ucb_realloc and untracked allocations with ucb_free.

Once enabled, cannot be disabled. Since all memory allocations will be wrapped with metadata and reallocations would invalidate existing pointers.

Allocations outside of ucb cannot be tracked.

See also
UCB_MEMTRACK_FINAL for the corresponding call before termination.
Note
This is only available in debug builds.
This must be done before any memory allocations are made using ucb functions.

◆ UCB_MEMTRACK_FINAL

#define UCB_MEMTRACK_FINAL ( )
Value:
ucb_mem_tracking_report(true)

Trigger a final report.

To be called just before program termination. It will generate a report of all memory still allocated as leaks.

Note
No actual cleanup is done and levels remain intact.
