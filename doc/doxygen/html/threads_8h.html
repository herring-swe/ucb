◆ ucb_thread_set_priority()

UCB_API void ucb_thread_set_priority ( ucb_thread * thread,
int priority )

Set the thread priority.

Only valid before the thread is started. The priority will be considered only if different from UCB_THREAD_PRIO_DEFAULT and mapped into the platform's priority range. Note, that increasing the priority may not be allowed. Any failure is logged only on debug builds as warnings.

Parameters
threadthe thread
prioritypriority between and including UCB_THREAD_PRIO_LOWEST and UCB_THREAD_PRIO_HIGHEST

◆ ucb_thread_set_stack_size()

UCB_API void ucb_thread_set_stack_size ( ucb_thread * thread,
size_t stack_size )

Set the minimum thread stack size.

Only valid before the thread is started. The default stack (0) will use the same stack size as the current thread. Any other size may be rounded up to a minimum + any necessary alignment. Recommended minimum and increments are 64 KiB for platform compatibility.

Parameters
threadthe thread
stack_sizesize in bytes

◆ ucb_thread_start()

UCB_API bool ucb_thread_start ( ucb_thread * thread,
ucb_task task )

Start a thread with the given task.

The task will be executed in the thread context. The thread priority is not updated from the task. This must be manually done before this call, if this is expected. This will clear any previous task status code and set the thread to running.

Warning
If the thread is detached, you must no longer use the ucb_thread pointer as it may free itself at any time.
Parameters
threadthe thread
taskthe task to execute
Returns
true if the thread was started

◆ ucb_thread_yield()

UCB_API void ucb_thread_yield ( void )

Yield the current thread, to allow other threads to run.

This is added for compatibility with existing logic. Normally it is better to use other synchronization mechanisms, such as conditions or mutexes, which allows the scheduler to know exactly what this thread is waiting for.

Note
This is a hint to the scheduler and may not be respected by all platforms.
