Detailed Description

Byte buffer type.

A byte buffer for storing sequential data. It can have multiple implementations.

Allocate on heap with ucb_buffer_new_<type> or initiate on stack with ucb_buffer_init_<type>

Only resize or free the buffer using the functions provided in the ucb_buffer namespace.

The buffer is not thread safe.

Warning
All of the possible resize functions may invalidate pointers to the current memory. For this reason, it is recommended to only use offsets.

Unsafe usage:

ucb_buffer* buf = ucb_buffer_new_heap(1024);
char* data = buf->data;
ucb_buffer_resize(buf, 2048);
data[0] = 'a'; // This is now invalid.
